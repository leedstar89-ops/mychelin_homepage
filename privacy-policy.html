개인정보처리방침

버전: 2026-08-22.1 · 시행일: 2026년 8월 22일 · Mychelin (마이슐랭) · 운영자: 이대규

이대규(이하 "운영자")는 Mychelin 서비스 이용자의 개인정보를 중요하게 생각하며, 개인정보 보호법 등 관련 법령을 준수합니다. 본 방침은 서비스가 어떤 개인정보를 수집하고 어떻게 사용하는지 설명합니다.

1. 처리하는 개인정보

서비스 가입·인증

구분 처리 항목 처리 목적
카카오 로그인 카카오가 발급한 서비스별 사용자 식별정보, OAuth 인증 결과 회원 인증과 동일 사용자 식별
Supabase Auth 사용자 UUID, 세션·JWT·Refresh Token, 로그인 및 세션 기록 로그인 유지, 접근 권한 확인, 보안
가입 프로필 사용자가 직접 입력한 닉네임, 선택한 프로필 사진, 언어 설정 프로필 제공, 서비스 표시
약관 기록 문서 종류, 버전, 확인·동의 여부 및 시각 가입 처리와 동의 이력 관리

서비스 이용 기록 (선택적)

  • 식당 방문 기록: 식당 식별자, 방문일, 맛·가격·특별함·분위기·재방문의사 평가, 메모, 사진
  • 공개 범위 설정: 전체공개 / 팔로워만 / 비공개
  • 소셜 활동: 팔로우, 가보고 싶은 곳 저장, 차단, 신고 내역
  • 이용 통계: 개인 취향 통계, 랭킹, 내보내기 요청 기록

카카오 계정 비밀번호는 수집하지 않으며, 열람할 수 없습니다. 로그인 인증은 카카오와 Supabase가 처리하고 서비스는 그 결과만 확인합니다.

2. 처리 목적

개인정보는 다음 목적으로만 처리합니다.

  • 카카오 로그인과 회원 식별
  • 개인 식당 방문 기록의 저장·조회·수정·삭제
  • 개인 취향 통계와 랭킹 제공
  • 사용자가 설정한 공개 범위에 따른 소셜 기능 제공 (팔로우, 가보고 싶은 곳, 차단, 신고)
  • 신고, 차단, 부정 이용 방지와 보안 대응
  • 문의 대응, 계정 내보내기 및 탈퇴 처리
  • 서비스 장애 분석과 품질 개선

수집한 개인정보는 위 목적 외의 다른 목적으로 사용하지 않습니다. 목적이 변경될 경우 사전에 알리고 필요한 동의를 받습니다.

3. 개인정보의 제3자 제공

서비스는 사용자의 개인정보를 판매하지 않습니다. 또한 다음의 경우를 제외하고 법적 요구가 없는 한 임의로 제3자에게 제공하지 않습니다.

  • 사용자가 사전에 명시적으로 동의한 경우 (공개 범위 설정 등)
  • 법령에 근거가 있거나 수사기관 등이 법적 절차에 따라 요구하는 경우
  • 서비스 제공을 위해 필수적인 위탁처리 (카카오 OAuth, Supabase Auth, 지도/검색 API 등) — 최소 범위만 전달

4. 카카오·Supabase 사용자 데이터의 처리

서비스는 카카오·Supabase 정책을 준수하며, 사용자 데이터를 다음과 같이 처리합니다.

  • 로그인 및 회원 식별, 세션 관리, 보안 목적으로만 사용
  • 광고, 프로파일링, 판매 등 서비스 제공 외 목적으로 사용하지 않음
  • 인공지능 학습 등에 사용하지 않음

5. 보관 기간 및 파기

사용자의 개인정보는 회원 탈퇴(계정 삭제) 시 지체 없이 파기됩니다. 다만 관련 법령에 따른 보존 의무가 있는 데이터는 법정 기간 동안만 보관 후 파기하며, 그 외 데이터는 삭제합니다.

  • 식당 방문 기록, 평가, 메모, 사진: 탈퇴 시 즉시 삭제 (또는 사용자 요청 시 선별 삭제)
  • 인증 토큰(UUID, JWT, Refresh Token): 세션 만료·로그아웃·탈퇴 시 파기
  • 약관 동의 기록: 분쟁 해결·법적 의무 준수를 위해 탈퇴 후 1년간 보관 후 파기
  • 신고·차단·부정이용 기록: 서비스 보호 목적으로 탈퇴 후 6개월간 보관 후 파기

6. 사용자의 권리 (열람 · 수정 · 삭제 · 내보내기)

이용자는 자신의 개인정보에 대해 다음 권리를 가집니다.

  • 열람: 서비스 내 프로필·설정에서 자신의 정보를 확인할 수 있습니다.
  • 수정: 닉네임, 프로필 사진, 언어 설정, 공개 범위는 서비스 내에서 직접 수정 가능합니다.
  • 삭제: 계정 삭제를 요청하면 관련 데이터가 개인정보처리방침에 따라 처리됩니다. 또는 카카오 계정 설정에서 서비스 연결을 해제할 수 있습니다.
  • 내보내기: 본인의 식당 방문 기록, 평가, 사진 데이터를 구조화된 형식(JSON/CSV)으로 내려받을 수 있습니다.

권리 행사는 문의 페이지의 이메일로 요청할 수 있으며, 본인 확인 후 지체 없이 처리합니다.

7. 만 14세 미만 아동의 개인정보 보호

Mychelin은 원칙적으로 만 14세 이상 사용자를 대상으로 합니다. 만 14세 미만 아동의 개인정보는 수집하지 않으며, 부득이 수집해야 할 경우 법정대리인 동의를 받습니다.

8. 쿠키 등 자동 수집 정보

서비스는 로그인 상태 유지를 위한 필수 쿠키(세션, Supabase JWT/Refresh Token) 외에 광고·추적 목적의 쿠키를 사용하지 않습니다.

9. 개인정보 보호 책임자

개인정보 관련 문의: support@mychelin.app (운영자: 이대규)

10. 방침의 변경

본 방침이 변경되는 경우(버전 번호 변경) 서비스 내 공지 또는 이메일로 알리며, 변경된 방침은 공지 시점부터 적용됩니다. 중요한 변경은 시행일과 변경 사유를 미리 안내합니다.
