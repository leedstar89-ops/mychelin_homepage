앱에서 직접 삭제

MY → 설정 → 계정 및 데이터 관리 → 회원 탈퇴 경로에서 즉시 탈퇴할 수 있습니다.

웹에서 삭제 요청

앱에 접근할 수 없는 경우 아래 정보를 포함하여 이메일로 요청해 주세요.

필수 정보:

  • @계정ID
  • 로그인 제공자 (카카오 등)
  • 회신 받을 이메일 주소

주의사항

비밀번호, 토큰, 인증번호, API 키를 이메일로 보내지 마세요. 운영자는 이를 요청하지 않습니다.
